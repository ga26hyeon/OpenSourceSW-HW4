# F1 Circuit Explorer

F1 팬이 Monaco, Monza, Silverstone, Suzuka, Spa-Francorchamps를 탐색하고 두 서킷을 비교하는 FastAPI 웹서비스입니다.

## 주요 기능

- 5개 F1 서킷 목록 및 상세 정보
- 길이, 코너 수, 레이스 랩 수, 서킷 유형 표시
- 서킷 선택에 따른 SVG 레이아웃 변경
- 두 서킷 비교 모드
- API, 데이터 로딩, 존재하지 않는 서킷 오류 처리
- PC·모바일 반응형 대시보드

## 기술 스택

Python 3.12, FastAPI, Uvicorn, HTML, CSS, JavaScript, JSON

## 설치 및 로컬 실행

PowerShell에서 이 폴더로 이동한 뒤 실행합니다.

```powershell
cd "D:\오픈소스SW개발방법및도구\과제\HW2_깃허브\f1-circuit-explorer\upload"
python -m pip install -r requirements.txt
python -m uvicorn main:app --reload
```

브라우저에서 `http://127.0.0.1:8000`을 엽니다.

## API

| Method | Endpoint | 설명 |
|---|---|---|
| GET | `/` | 메인 웹페이지 |
| GET | `/api/circuits` | 전체 서킷 목록 |
| GET | `/api/circuits/{circuit_id}` | 특정 서킷 상세 정보 |
| GET | `/health` | 서버 상태 확인 |

## 데이터 및 이미지 출처

서킷 수치의 기준 시즌은 `circuits.json`의 `season_basis`에 기록했습니다. 길이·랩 수·코너 수는 Formula1.com의 공식 회로 안내 및 공식 티켓 안내 자료를 대조했습니다.

SVG는 공식 F1/FIA 이미지를 복제하지 않기 위해 프로젝트에서 직접 작성한 참고용 schematic입니다. 공식 트랙맵으로 교체할 경우 해당 자료의 라이선스와 출처를 확인하고 `layout_status` 및 README를 갱신해야 합니다.

## Render 배포

Render에서 **New → Web Service**를 선택하고 이 `upload` 폴더를 저장소의 루트로 업로드합니다.

- Runtime: `Python 3`
- Build Command: `pip install -r requirements.txt`
- Start Command: `uvicorn main:app --host 0.0.0.0 --port $PORT`

또는 저장소 루트에서 `render.yaml`을 사용한 Blueprint 배포가 가능합니다.
